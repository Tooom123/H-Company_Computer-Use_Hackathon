# CapCut Web coaching reference

Reference checked on 2026-11-08. Experimental: no prepared demo project or
authenticated app walkthrough yet. Answer in English. Match visible labels;
the Web, Desktop and Mobile interfaces differ.

## Correct an existing caption

In CapCut Online, the official help describes selecting a subtitle block in
the timeline, then Edit captions in the right panel, then editing the relevant
line. Edits save in real time. Prefer a disposable copy of the project for a
demo. Showing where to edit is different from actually changing its contents.
Source: https://www.capcut.com/help/auto-captions-in-capcut

## Check timing and segmentation

Read the selected segment and timeline before proposing an edit. The help
describes splitting a selected caption at the playhead through the scissors
control. Do not prescribe a shortcut without checking the active surface.
Screenshots alone cannot verify audio/text synchronization: replay with sound
and obtain a human judgment. Do not label an export or synchronization successful
from an agent's claim alone.
Source: https://www.capcut.com/help/auto-captions-in-capcut

## Generating captions and costs

The help describes Text → Auto Captions, language selection and Generate for
Web. Availability and entitlement must be checked in the current account.
Do not regenerate captions, delete tracks, export, publish or start a paid
feature when the request is only to explain or locate a control. Canvas and
timeline content may be missing from Accessibility; report that limitation
instead of inventing a target.
Source: https://www.capcut.com/help/auto-captions-in-capcut
