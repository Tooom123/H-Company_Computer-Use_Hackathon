# hcs-agent (Matteo)

Python component that drives the user's software through H's `desktop` environment, with explicit approval,
a local stop gate, verified results and a structured report for support. Exposes a local HTTP/WebSocket API
on `127.0.0.1:8765` for the Electron app.

Implementation is on branch `matteo`; see its README for setup, macOS permissions and commands.
